## 🎮 猜数字游戏玩法

两个版本功能一致：

1. 程序随机生成一个 **1 ~ 100** 之间的数字
2. 你输入猜测的数字
3. 程序提示 **"太大了"** 或 **"太小了"**
4. 直到猜对为止，显示总猜测次数

**运行方式：**

```bash
# Python 版
python guess_number.py

# C 语言版
gcc guess_number.c -o guess_number
./guess_number
```
