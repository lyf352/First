## 🎮 猜数字游戏玩法

两个版本功能一致：

1. 程序随机生成一个 **1 ~ 100** 之间的数字
2. 你输入猜测的数字
3. 程序提示 **"太大了"** 或 **"太小了"**
4. 直到猜对为止，显示总猜测次数

**运行方式：**

```bash
# Python 版
python guess_number.py

# C 语言版
gcc guess_number.c -o guess_number
./guess_number
```

## 🐍 贪吃蛇游戏玩法

用 **pygame** 写的图形界面版本，运行前先装一下：

```bash
pip install pygame
```

**运行方式：**

```bash
python snake.py
```

**玩法：**

1. 用 **方向键 ↑ ↓ ← →** 控制蛇的移动
2. 吃掉红色的食物加 **1 分**，蛇身会变长一节
3. 撞到墙壁或者自己的身体就结束
4. 结束后窗口里会显示最终得分

**按键说明：**

| 按键 | 作用 |
|------|------|
| `↑` `↓` `←` `→` | 控制蛇的方向（不能直接掉头） |
| 窗口的 `×` | 退出游戏 |

**从这个游戏里学到的：**

- 游戏主循环：`while` 里不断重复「处理事件 → 更新数据 → 重新画画面」
- 用列表表示蛇身，`insert(0, ...)` 加蛇头、`pop()` 去掉蛇尾
- 碰撞判断：撞墙比较坐标，撞自己用 `in` 判断
- 用 `clock.tick(10)` 控制蛇的速度
